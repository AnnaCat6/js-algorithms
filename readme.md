# js-algorithms

Учебный репозиторий по модулю «Алгоритмика» (поток Алгоритмика‑7).  
Здесь собираю практики, функции и решения задач, чтобы закрепить работу с алгоритмами и структурой кода.

## Что внутри

- `homework.md` — мои цели на модуль, конспекты статей и заметки о прогрессе.
- Практики и функции для работы со строками — будут появляться по ходу модуля.
- Вспомогательные файлы (`.gitignore`, скрипты) — для корректной работы Git и чистоты репозитория.

## Что сделано

Реализованы 7 функций для сравнения строк (библиотека string-utils):

- len(str) — длина строки
- isEqual(a, b) — посимвольное равенство
- isNotEqual(a, b) — неравенство
- isMore(a, b) — лексикографическое «больше»
- isLess(a, b) — лексикографическое «меньше»
- isMoreOrEqual(a, b) / isLessOrEqual(a, b) — «больше/меньше или равно»

Все функции реализованы через TDD: тесты → реализация → рефакторинг.
Аргументы валидируются: TypeError для не-строк, RangeError для диапазонов.
