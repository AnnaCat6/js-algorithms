# js-algorithms

Учебный репозиторий по модулю «Алгоритмика» (поток Алгоритмика‑7).  
Здесь собираю практики, функции и решения задач, чтобы закрепить работу с алгоритмами и структурой кода.

## Что внутри

- `homework.md` — мои цели на модуль, конспекты статей и заметки о прогрессе.
- Практики и функции для работы со строками — будут появляться по ходу модуля.
- Вспомогательные файлы (`.gitignore`, скрипты) — для корректной работы Git и чистоты репозитория.

В папке `string-utils` реализованы 7 функций для сравнения строк и работы с длиной:

- `len(str)` — возвращает длину строки.
- `isEqual(a, b)` — проверяет строки на полное равенство.
- `isNotEqual(a, b)` — проверяет строки на неравенство.
- `isMore(a, b)` — лексикографическое сравнение: `a > b`.
- `isLess(a, b)` — лексикографическое сравнение: `a < b`.
- `isMoreOrEqual(a, b)` — `a >= b`.
- `isLessOrEqual(a, b)` — `a <= b`.

Все функции написаны с учётом типов и длины строк, покрыты тестами.
