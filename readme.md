Здесь собираю практики, функции и решения задач, чтобы закрепить работу с алгоритмами и структурой кода.

## Что внутри

- `homework.md` — мои цели на модуль, конспекты статей и заметки о прогрессе.
- Практики и функции для работы со строками — будут появляться по ходу модуля.
- Вспомогательные файлы (`.gitignore`, скрипты) — для корректной работы Git и чистоты репозитория.

## Зачем этот репозиторий

Это не готовый продукт, а тренировочная площадка: здесь я учусь:
- грамотно организовывать файлы и структуру проекта;
- работать с Git (ветки, коммиты, Pull Request);
- писать чистый, понятный код на JavaScript.

Поэтому в **README** сознательно оставляю место для роста: по мере прохождения модуля буду добавлять разделы, инструкции запуска и примеры использования.
